# Support

**WODrounds** is a minimal EMOM and Intervals timer for workouts.

## Getting help

- **Bugs or feature requests:** Open an issue on the app’s GitHub repository (see link in App Store or in-app About).
- **General questions:** Use the Support URL linked in the app’s About screen.

We don’t use analytics or tracking. On iOS we do send crash and error reports to Sentry so we can fix bugs; if you experienced a crash we may have received anonymized crash data. For other issues please describe your device (e.g. iPhone 15, iOS 17) and what you were doing when the issue occurred.
