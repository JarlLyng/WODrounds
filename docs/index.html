The app

Built for the workout

  • EMOM

    EMOM

    Set rounds (1–120). Each round is one minute. Large numbers, one-handed use.

  • Work / Rest

    Intervals

    Work seconds, rest seconds, rounds. Tabata-style (e.g. 20/10 × 8) is just a preset.

  • ⌚

    iPhone → Watch

    Start on iPhone. The Watch shows the same timer in real time. Or run the timer locally on the Watch.

  • ❤️

    Apple Health

    Completed workouts (HIIT) save to Health so Fitness and Activity reflect your training.

A tool, not a feed

WODrounds is for functional fitness, CrossFit-style WODs, HIIT and interval sessions. Ultra-minimal UI, date-based timing that works when the app is in the background, and a native Apple experience across devices.

  • No sign-in or accounts
  • No analytics or tracking
  • No workout database in the cloud
  • Local-first; optional Health write-only
